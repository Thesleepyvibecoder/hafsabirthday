# Hafsa The Great Birthday Website — V4 Framework

This version establishes the project structure before we fill in the final personal copy.

## Experience flow
1. Locked countdown entry
2. Midnight unlock (Karachi / PKT, UTC+5)
3. Biryani-cake + candle interaction
4. Enter the birthday
5. Existing navigation framework: Memories / Reasons / Letter / Cake / Final

## Development preview
Open the entry page with `?preview=unlock` to test the midnight reveal immediately.
Example: `index.html?preview=unlock`

## Production behavior
The preview flag is ignored unless it is explicitly present in the URL. The normal site remains locked until 16 September 2026, 12:00 AM PKT.

## Design rule
Preserve the original template's layout, rounded navigation, buttons, typography system, and interactions where they are good. Replace generic content gradually with Hafsa-specific content, images, audio, and new interactions.
